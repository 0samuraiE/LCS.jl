Flows API

Incompressible flow field computation with forcing and coupling.

Configuration

LCS.Flows.FlowConfig — Type
FlowConfig <: LCS.AbstractConfig

Main configuration struct for flow simulation.

Fields

  • params: Flow physical parameters
  • init: Flow field initialization method
  • couple: Pressure-velocity coupling method
  • forcing: Flow forcing method
  • stat: Flow statistics options
LCS.Flows.FlowParams — Type
FlowParams

Flow parameters defining the physical properties of the simulation.

Fields

  • U0_m_s: Reference velocity scale [m/s]
  • L0_m: Reference length scale [m]
  • NU_m2_s: Kinematic viscosity [m²/s]

Operators

LCS.Flows.init! — Function
init!(buf, state, config, topo)

Initialize flow fields based on the configured initialization method.

LCS.Flows.rhs! — Function
rhs!(buf, state, config, topo, stage)

Compute right-hand side of incompressible Navier-Stokes equations.

LCS.Flows.update! — Function
update!(buf, state, config, topo, stage)

Update velocity fields using explicit Runge-Kutta time integration.

LCS.Flows.couple! — Function
couple!(buf, state, config, topo, stage)

Apply pressure-velocity coupling to enforce incompressibility constraint.

LCS.Flows.forcing! — Function
forcing!(buf, state, config, topo, stage)

Apply flow forcing based on the configured forcing method.

forcing!(forcing, buf, state, config, topo, stage)

Apply ConstantPowerLF forcing: scales velocity fluctuations to inject constant power.

timestep(buf, state, config, topo)

Compute adaptive time step size for stable flow simulation.

LCS.Flows.timestep! — Function
timestep!(buf, state, config, topo)

Update time step in state based on stability constraints.

Init

Abstract type for flow field initialization methods.

LCS.Flows.RandomFlow — Type
RandomFlow <: Init

Initialize flow field with random velocity fluctuations.

Fields

  • seed: Random seed for reproducible initialization
LCS.Flows.IdealFlow — Type
IdealFlow <: Init

Initialize flow field with ideal (analytical) velocity solution.

Forcing Schemes

LCS.Flows.Forcing — Type
Forcing

Abstract type for flow forcing methods.

LCS.Flows.RCForcing — Type
RCForcing

Reduced Communication Forcing method for maintaining turbulent flow.

LCS.Flows.EnergyPreserveRCF — Type
EnergyPreserveRCF <: RCForcing

Reduced Communication Forcing that maintains constant kinetic energy.

Fields

  • energy: Time-varying target energy
  • kmin: Minimum wavenumber shell for forcing
  • kmax: Maximum wavenumber shell for forcing
  • coarse_size: Size of coarse grid for forcing generation
LCS.Flows.NoForcing — Type
NoForcing <: Forcing

No external forcing applied to the flow.

Coupling Schemes

LCS.Flows.Couple — Type
Couple

Abstract type for pressure-velocity coupling methods.

LCS.Flows.HSMAC — Type
HSMAC <: Couple

HSMAC (Highly Simplified Marker and Cell) pressure-velocity coupling method.

Fields

  • time_blocking: Enable time-blocking
  • overlap: Enable computation-communication overlap
  • coloring: Coloring scheme for parallel iteration
  • omega: SOR relaxation parameter (1.0 < ω < 2.0)
  • epsp: Pressure convergence tolerance
  • itrmin: Minimum iteration count
  • itrmax: Maximum iteration count

Statistics

LCS.Flows.Stat — Type
FlowStatConfig

Configuration for flow statistics computation.

LCS.Flows.FlowStat — Type
FlowStat <: LCS.AbstractStat

Flow statistics containing computed turbulence parameters.

Fields

  • u: Velocity statistics in x-direction
  • v: Velocity statistics in y-direction
  • w: Velocity statistics in z-direction
  • k: Turbulent kinetic energy
  • ϵ: Dissipation rate
  • τη: Kolmogorov time scale
  • lμ: Taylor microscale
  • lη: Kolmogorov length scale
  • Reλ: Taylor Reynolds number
  • urms: Root mean square velocity
  • kη: Kolmogorov wavenumber
  • skew: Skewness of velocity gradient
  • flat: Flatness of velocity gradient
  • L: Integral length scale
  • Cϵ: Dissipation coefficient (ϵL/u'³)
LCS.Flows.stat — Function
stat(buf, state, config, topo)

Compute flow statistics from current velocity field.

Q(buf, state, config, topo)
