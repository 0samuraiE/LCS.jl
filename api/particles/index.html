Particles API

Lagrangian particle advection with drag models and initialization.

Configuration

LCS.Particles.ParticleConfig — Type
ParticleConfig <: LCS.AbstractConfig

Main configuration struct for particle simulation.

Fields

  • population: Particle population configuration
  • params: Physical parameters
  • cell: Cell-based indexing configuration
  • stat: Statistics configuration
  • drag: Drag force model
  • init: Initialization configuration
LCS.Particles.ParticleParams — Type
ParticleParams

Physical parameters for particle dynamics.

Fields

  • gravity: Gravitational acceleration (non-dimensional)
  • density_ratio: Particle to fluid density ratio (ρₚ/ρf)
LCS.Particles.Population — Type
Population

Particle population configuration.

Fields

  • valid: Total number of valid particles across all processes
  • invalid_ratio: Ratio of buffer space for invalid particles
  • exchange_ratio: Ratio of buffer space for particle exchange between processes
LCS.Particles.Cell — Type
Cell

Cell-based particle tracking configuration.

Fields

  • grid_ratio: Coarsening ratio relative to flow grid

Operators

init!(buf, state, config, topo, iprofile)

Initialize all particle properties for a specific particle set.

motion!(buf, state, config, topo, stage, iprofile)

Compute particle equations of motion.

LCS.Particles.update! — Function
update!(buf, state, config, topo, stage, iprofile)

Update particle positions and velocities using explicit Runge-Kutta time integration.

LCS.Particles.boundary! — Function
boundary!(buf, state, config, topo, stage, iprofile)

Apply boundary conditions and exchange particles between MPI processes.

timestep(buf, state, config, topo)

Compute adaptive time step size for particle simulation.

LCS.Particles.timestep! — Function
timestep!(buf, state, config, topo)

Compute adaptive time step for particle simulation.

Initialization

LCS.Particles.Init — Type
Init

Particle initialization configuration combining ID, position, velocity, and size initialization.

Fields

  • id: ID initialization method
  • position: Position initialization method
  • velocity: Velocity initialization method
  • size: Size initialization method
LCS.Particles.InitId — Type
InitId

Abstract type for particle ID initialization methods.

LCS.Particles.GenerateId — Type
GenerateId <: InitId

Generate unique particle IDs for each particle.

LCS.Particles.InitPosition — Type
InitPosition

Abstract type for particle position initialization methods.

LCS.Particles.RandomPosition — Type
RandomPosition <: InitPosition

Initialize particle positions randomly in domain.

LCS.Particles.InitVelocity — Type
InitVelocity

Abstract type for particle velocity initialization methods.

LCS.Particles.RestVelocity — Type
RestVelocity <: InitVelocity

Initialize particles at rest (zero velocity).

LCS.Particles.InitSize — Type
InitSize

Abstract type for particle size initialization methods.

LCS.Particles.ConstSize — Type
ConstSize <: InitSize

Initialize all particles with constant diameter.

Fields

  • diam_m: Particle diameter [m]

Drag Models

LCS.Particles.DragModel — Type
DragModel

Abstract type for drag force models.

LCS.Particles.LinearDrag — Type
LinearDrag <: DragModel

Linear Stokes drag model.

LCS.Particles.NonlinearDrag — Type
NonlinearDrag <: DragModel

Nonlinear drag model with Reynolds number correction using Schiller-Naumann correlation.

Statistics

LCS.Particles.ParticleStat — Type
ParticleStat <: LCS.AbstractStat

Particle statistics containing computed particle properties.

Fields

  • x: Position statistics in x-direction
  • y: Position statistics in y-direction
  • z: Position statistics in z-direction
  • u: Velocity statistics in x-direction
  • v: Velocity statistics in y-direction
  • w: Velocity statistics in z-direction
  • diam: Particle diameter statistics
  • τp: Mean particle response time
  • St: Stokes number (τp / τη)
  • rdf: Radial distribution function statistics
  • spectrum: Particle number density spectrum statistics
LCS.Particles.stat — Function
stat(fstat, buf, state, config, topo, iprofile)

Compute particle statistics.

density(buf, state, config, topo, iprofile)

Compute SPH (Smoothed Particle Hydrodynamics) density estimate for each particle.
